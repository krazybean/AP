# Security Policy

## Scope

This policy covers the AP and APP implementation maintained in this repository.

## Supported versions

Only the current `security/integration` release line and the default branch are expected to receive security fixes. Older commits are not supported as deployment baselines.

## Reporting a vulnerability

Please use GitHub's Private Vulnerability Reporting for this repository when it is enabled. Do not open a public issue for an exploitable vulnerability. If private reporting is not enabled, contact the repository maintainers through an authenticated private channel before sharing details; this repository does not currently publish a dedicated security email address.

Include the affected commit or deployment, endpoint/configuration, reproduction steps, impact, and any logs or proof of concept needed to validate the issue. Remove secrets and personal data from reports.

Maintainers will acknowledge and investigate reports, coordinate a fix and disclosure plan with the reporter where practical, and publish details only after affected users have a reasonable mitigation. Do not publicly publish exploitable details before coordination.
